

# 🌙 Sufrah (سفرة) - Ramadan Recipes Platform

## 📌 Overview

**Sufrah** is a web-based platform dedicated to Ramadan culinary traditions. The project focuses on providing a collection of authentic Ramadan recipes while offering healthier alternatives and modifications to traditional dishes, helping users maintain a balanced diet during the Holy Month.

## 🎯 Key Features

* **Recipe Catalog:** Browse and explore diverse Ramadan recipes.
* **Health-Conscious Choices:** Tagging and categorization for healthy meal alternatives.
* **Interactive Map:** A feature integrated into the index page to help users navigate culinary locations.
* **User Interaction:** Users can rate, like, and comment on recipes to engage with the community.
* **Admin Dashboard:** A robust management interface for administrators to manage reports, block inappropriate content, and maintain platform quality.
